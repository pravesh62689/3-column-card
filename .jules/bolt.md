## 2024-05-14 - CSS @import Blocking Behavior
**Learning:** Found duplicate `@import` statements for Google Fonts in both `style.css` and `mediastyle.css`. The `@import` rule blocks parallel downloads and causes a performance bottleneck because the browser has to first download the CSS file, parse it, discover the `@import`, and then initiate the font download. The duplicate imports would potentially cause even more overhead or duplicate network requests depending on browser caching behavior.
**Action:** Always prefer `<link rel="stylesheet">` with `<link rel="preconnect">` in the HTML `<head>` over CSS `@import` for external web fonts to allow for early discovery and parallel downloading. Look for duplicate `@import` statements across different stylesheets, especially media query specific stylesheets.
